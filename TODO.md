# Things to do later

- [ ] **LinkedIn newsletter.** Create an "Ahead of Main" newsletter on LinkedIn (Write article, then Create a newsletter), then put its URL in `linkedinNewsletter` in `src/config.ts`. That turns on the "Subscribe on LinkedIn" button on the home page, issue pages and About page. After that, paste each merged issue into it (steps in [docs/publishing.md](docs/publishing.md)).
- [ ] **Custom domain.** aheadofmain.com is bought on Cloudflare. Add the DNS records and set it under Settings, then Pages, then Custom domain (steps in [docs/publishing.md](docs/publishing.md)).
- [ ] **Email list.** Once about 100 people read regularly, add Buttondown (or similar) as RSS-to-email using `/rss.xml`, so you own a subscriber list.
