This issue covers a full week, 12 to 19 November. GPT-6.2 and Anthropic's IPO took the headlines. Underneath them, three things changed how agent work gets run, measured and paid for. One sign on the Watch board was met, but no entry moved.

## The top 3

### 1. Claude Code's unattended runs now ask, or are refused, where they used to just run

**ACT NOW** High confidence.

Claude Code shipped versions 2.1.323 to 2.1.328 this week, and most of their changes are permission defaults:

- **Sandboxed Bash now follows the normal permission flow** (2.1.325). Set `sandbox.autoAllowBashIfSandboxed: true` to keep the old behaviour.
- **Scheduled tasks and `/loop` ask before running a skill that declares `allowed-tools` or hooks.** Add `Skill(name)` to `permissions.allow` to run it unattended.
- **"Always allow" is offered less often** in desktop, IDE and SDK hosts, "so a scheduled task that relied on one can now wait for you".
- **Auto mode ignores broad allow rules**, such as rules that name no program or run any package (`Bash(pnpm dlx *)`), and its billed-classifier fallback is going away. Each action it would have checked "will be asked about or denied".
- **`/status` now lists ignored permission settings**, hook matchers that never match and an unavailable sandbox.

Version 2.1.323 also added Code Mode, an experimental option in which Claude writes JavaScript that makes several tool calls in one step. Auto mode's classifier then reviews the script, not each call.

**Why it matters:** the familiar risk is an agent doing something it shouldn't. This week's risk is the reverse: a scheduled job stops at a prompt nobody will answer and reports success after doing nothing. Update, run `/status` in every repo that runs unattended, add allow rules for the skills your jobs call, and end each job with a check that the work happened.

Sources: [Claude Code changelog 2.1.323–2.1.328](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md), [Code Mode documentation](https://code.claude.com/docs/en/code-mode)

### 2. GitHub turns evals and harness comparisons into product features

**ACT NOW** High confidence.

GitHub Copilot Evals entered public preview on 17 November. `/eval` builds a repeatable test for a skill, custom agent or MCP tool, runs it, explains failed checks and compares runs before and after a change. The same day, GitHub's benchmarks site added a Harnesses view that compares Copilot CLI, Claude Code and Codex CLI on the same model at the same effort, plotting success rate against cost per task. GitHub says "much of the work we do to make Copilot better happens at the harness-level." VS Code will remove its older Local harness in February 2027. Vercel published its own eval method the same week, built with Harbor, the Terminal-Bench team's open-source runner.

**Why it matters:** the agent harness is now something vendors measure and compete on, separately from the model. Treat it as a variable: run the same handful of real tasks through two harnesses before you standardise on one. If you build agents for others, ship the eval with them, so every model or skill change can be checked in minutes.

Sources: [Copilot Evals](https://github.blog/changelog/2026-11-17-github-copilot-evals-is-now-in-public-preview), [Harness comparisons](https://github.blog/changelog/2026-11-17-github-copilot-benchmarks-site-adds-harness-comparisons), [Copilot Fusion](https://github.blog/changelog/2026-11-17-github-copilot-fusion-updates-more-availability-benchmarks-and-models), [VS Code Local harness retirement](https://github.blog/changelog/2026-11-16-vs-code-retires-the-local-harness-in-february-2027), [Vercel on agent evals](https://vercel.com/blog/agent-evals)

### 3. Your customers can pay for their own Claude usage, and platforms get hard caps

**WATCH** Medium confidence.

Anthropic launched Linked billing in beta on 17 November: "Your customers can now pay for the Claude usage in your app through their own Claude organization." You set `billing_policy` on each request to choose who pays, and the customer can cap what your app spends. It works only for customers whose organisation pays Anthropic directly. The same week, Cloudflare added spending limits that block Workers and Durable Objects usage at a cap, and Vercel added project budgets that can pause production deployments.

**Why it matters:** if you build AI features for clients, inference can move from a cost you estimate and absorb to a line on the client's own bill, under their cap. That changes how you quote. And anything running agents unattended needs a hard cap today.

Sources: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview), [Cloudflare spending limits](https://developers.cloudflare.com/changelog/post/2026-11-13-spend-management/), [Vercel project budgets](https://vercel.com/changelog/set-budgets-for-projects-and-products-in-spend-management)

## Signal radar

### An AI gateway joins CISA's exploited list

**ACT NOW** High confidence.

CISA added LiteLLM CVE-2026-40217 to its Known Exploited Vulnerabilities catalog on 18 November: remote code execution through the `/guardrails/test_custom_code` endpoint, rated 8.8, in versions up to 8 April 2026. A week earlier it added GPUStack, an AI-serving tool. LLM gateways sit in front of every "any harness, any model" setup, and attackers are now using bugs in them. If you run a LiteLLM proxy, check its version.

Sources: [CISA KEV feed](https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json), [NVD CVE-2026-40217](https://nvd.nist.gov/vuln/detail/CVE-2026-40217)

### Decision models reach five vendors

**WATCH** High confidence.

Microsoft's Decision-1.1 is "better calibrated" than Decision-1, so its probabilities can drive act, review or escalate thresholds. Parallel Decisions answers typed questions by searching the live web and citing evidence. Vercel's eve 1.0 framework screens every incoming message with a small decision model before starting an agent turn. With OpenAI, Google and TypeSafe, five vendors now sell them. See SO-Arena below before you trust one.

Sources: [Decision-1.1](https://vercel.com/changelog/decision-1-1-now-available-on-ai-gateway), [Parallel Decisions](https://vercel.com/changelog/parallel-decisions-now-available-on-ai-gateway-for-free), [eve 1.0](https://vercel.com/blog/eve-is-now-generally-available)

### Browser vendors ship skills for coding agents

**WATCH** Medium confidence.

Modern Web Guidance is a set of agent skills with web best practices and browser compatibility data, maintained by the Chrome, Edge, Firefox and MDN teams, with a public eval dashboard. Two weeks ago Supabase shipped skills with a library release. Expect your framework vendors to do the same.

Source: [Modern Web Guidance README](https://raw.githubusercontent.com/GoogleChrome/modern-web-guidance-src/HEAD/README.md)

## Research frontier

### [SWE-CoWork: Benchmarking Coding Agents as Digital Employees in Organizations](https://arxiv.org/abs/2611.20218)

**ACT NOW** High confidence. Horizon: already shipping. Tokenwave.AI.

Agents had to gather requirements from 26 simulated colleagues across 101 real repositories. The two best models passed about 63% of the target tests but fully completed under 8% of assignments, and 31% of requirements agents reported as done failed their tests. Track requirements outside the agent, one check each, and close tasks from the checks.

### [Reducing Inference Cost of Coding Agents with Timeout Cascades](https://arxiv.org/abs/2611.24324)

**ACT NOW** Medium confidence. Horizon: already shipping. Affiliation not stated on the abstract page.

Across 36 open-weight models, small models nearly matched large ones on easy and medium tasks. Trying the small model first and escalating on failure or timeout cut GPU-hours by up to 33% on SWE-bench Verified without losing accuracy, nearly matching a perfect router. You don't need a learned router to save money.

### [SO-Arena: Benchmarking the Capability Spectrum and Reliability of System One Models](https://arxiv.org/abs/2611.15777)

**WATCH** Medium confidence. Horizon: 12 months. National University of Singapore.

Across 21 fast decision models, the best overall model ranked only seventh on reliability: answers shifted when the option list changed, and models missed that no option was valid. Test any decision model with shuffled options and a "none of these" case before gating a step on it.

## New capabilities to adopt

### Hard spend caps

**ACT NOW**

Cloudflare: Billing, then Spend limits, for Workers and Durable Objects. Vercel: `vercel billing budgets set --project my-app --amount 100 --pause`. About 10 minutes per project.

### Claude Code's Code Mode

**ACT NOW**

Start a session with `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 claude` (v2.1.323 or later, interactive terminal only) and give it a search-heavy task. Press Ctrl+O to read the code it wrote. About 15 minutes.

### eve 1.0

**WATCH**

Vercel's open-source agent framework reached 1.0. Every step is saved, so an agent resumes from its last completed step after a crash. Traces record approval decisions and export to OpenTelemetry. About two hours for a Slack prototype.

### `gh event listen`

**WATCH**

GitHub CLI 2.105.0 can block until a pull request gets a review, check result or merge conflict, replacing polling loops in agent scripts. It needs the Event Streams preview. About 15 minutes.

## Architecture & practice shifts

### Test that unattended agents still do the work

**ACT NOW**

Guardrail tests prove bad actions are blocked. Now add the other half: every scheduled job ends with a ground-truth check (a commit landed, a file changed) that fails the job if nothing happened.

### Cheap first, escalate on failure

**ACT NOW**

Route by trying a cheap model under a budget, not by predicting difficulty. Keep model, budget and escalation order in config.

### The sandbox becomes the permission boundary

**WATCH**

Claude Code made sandboxed commands ask by default, and OpenAI explained how the Codex sandbox enforces filesystem and network limits. Simon Willison and Prime Radiant released an "external sandbox" pattern: code runs in a separate sandbox behind an allow-list proxy that swaps in credentials, so the agent never sees a secret.

## This week's experiment

**Build:** a timeout cascade for one repository. Pick five recent tasks that a test or script can prove done. For each, run the task in a fresh worktree with a cheap model under a time limit, for example `timeout 300 claude -p "<task>" --model claude-haiku-5-5 --output-format json`. If the check fails or time runs out, rerun it in a new worktree with a stronger model. Then run all five on the stronger model alone. Record pass or fail from your check, cost from the JSON, and whether each task escalated.

**Done when:**

1. A table shows each task with cheap pass, escalated, cascade cost, strong-only cost and final pass.
2. Every pass is judged by a test or script, and each run is confirmed to have changed files.
3. You can say what the cascade saved, and whether any task lost its pass.
4. The routing rule you chose is written into the repository's config or agent instructions.
